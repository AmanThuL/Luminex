## 2. Trends since 2023

**RT-GI has moved from optional showcase to load-bearing default at the high end, but is not universal.** Doom: The Dark Ages makes hardware RT mandatory with no raster fallback; Assassin's Creed Shadows, Spider-Man 2, Alan Wake 2, Star Wars Outlaws and Indiana Jones and the Great Circle all ship RT-GI or full path tracing as a primary (sometimes only) lighting mode, and Ubisoft has stated RT-GI is now "the basis" for future Assassin's Creed titles. But the counter-evidence is just as real: Elden Ring: Nightreign (2025), a commercially huge title, shipped with no ray tracing at all and a hard 60fps engine cap; Overwatch 2's GI modernization (REAC 2025) explicitly targets a huge non-RT hardware spread; Dragon Age: The Veilguard uses baked probe GI with RT as an optional layer. So RT-GI is now the assumed *ceiling* for prestige, high-end, RT-required titles, but probe/baked/surfel GI remains a live, actively-developed production choice for broad-reach titles — this bears directly on how M8/M11 should be sequenced for a solo Metal-4 renderer without a fallback raster GI budget.

**GPU-driven geometry (culling, indirect submission, virtualized/meshlet geometry) is now mainstream, independently converged-upon, not an Epic-only bet.** Nanite is the most visible example, but Eidos-Montréal's Deferred+ (GPU culling + DX12 indirect draws), Ubisoft Anvil's "GPU-driven pipelines," Capcom RE Engine's meshlet pipeline (Dragon's Dogma 2, Monster Hunter Wilds), Remedy Northlight's mesh-shader culling (Alan Wake 2), Sucker Punch's GPU-first instance processing (Ghost of Yōtei), and Unity's shipped GPU Resident Drawer all independently arrived at essentially M7's ask (GPU scene tables + GPU culling + indirect submission) between 2023 and 2025. This is squarely "current industry baseline," not circa-2020 thinking — if anything it is slightly *behind* where a 2026 review should start, since mesh-shader-based meshlet rendering (not just indirect-draw culling of whole meshes) is now the more advanced variant several studios have already shipped.

**Direct/local lighting is having its own "Nanite moment."** MegaLights (Epic), Diablo IV's RT retrofit, and HypeHype's stochastic tile-based lighting all point to stochastic/ReSTIR-flavored direct lighting with many dynamic shadowed lights becoming the next commodity feature, displacing clustered Forward+'s classic light-list-per-cluster model as the ceiling technique (though clustered Forward+ remains a perfectly reasonable, much simpler baseline most titles still use).

**ML upscaling, frame generation, and ray reconstruction are now baseline, not novelty — and are actively still changing architecture.** DLSS went from CNN to a transformer model in DLSS4 (2025) and again in DLSS4.5 (2026); PSSR shipped on PS5 Pro and reached a "PSSR 2" revision; even Nintendo Switch 2, a handheld-first device, ships two different DLSS variants. Frame generation moved from a single extra frame (DLSS3, 2022) to "6x Dynamic Multi Frame Generation" by 2026. Full ReSTIR path tracing, however, is explicitly still research-stage (NVIDIA's own "ReSTIR PT Enhanced" paper, 2026, frames it as merely "closer to production-ready"), and neural rendering primitives (Cooperative Vectors/SM6.9, neural texture compression) only reached cross-vendor API standardization in 2025 with limited shipped adoption (Doom: The Dark Ages is the standout example). Mesh shaders, similarly, went from "will 2024 be the year of the mesh shader" skepticism to genuinely shipped in several AAA titles (Alan Wake 2, Space Marine 2, Dragon's Dogma 2/Monster Hunter Wilds) by 2024–2025.

## 3. What the M7–M11 plan gets right, and what looks dated

**Gets right:** M7's GPU scene tables + GPU frustum culling + indirect submission is not dated at all — it is precisely what Eidos-Montréal, Ubisoft Anvil, Remedy Northlight, and Unity's GPU Resident Drawer independently shipped in 2023–2025, and it is a genuinely tractable, well-understood scope for a solo developer (it is largely CPU-pipeline restructuring plus indirect-draw/dispatch support Luminex's RHI already has). Clustered Forward+ for point/spot lights as an M7 baseline is reasonable and matches what most non-flagship titles still ship (Overwatch 2's GI talk implicitly assumes a non-exotic direct-lighting model too). M8's sun cascades/PCSS, shadow atlas, GTAO, and atmosphere/froxel fog are all long-proven, still-shipping techniques (froxel fog dates to Doom 2016-era id Tech and remains standard); nothing there is stale. M10's framing of RT as "acceleration structures + inline ray queries, then a progressive path-trace *oracle*, then real-time RT reflections+denoiser" — i.e., RT arriving late and scoped narrowly — is actually well-aligned with the Nightreign/Overwatch-2 evidence that RT-GI, while increasingly prestigious, is still not universal, and matches NVIDIA's own admission that full ReSTIR path tracing remains research-stage.

**Looks dated or under-scoped against 2023–2026 practice:** (1) M8's "basic transparency" and M9's "ordinary LOD" read as more conservative than where mid-size internal engines already are — RE Engine and Northlight shipped meshlet-based geometry pipelines, and Activision shipped a genuinely novel OIT algorithm (AVBOIT) in a live title, in the same window this roadmap treats as introductory-tier. (2) M9's "offline LOD" as a first step, with meshlets/mesh-shaders as a later, separate milestone, undersells how tightly those two are now coupled in shipped engines (Alan Wake 2's LOD *is* its mesh-shader meshlet pipeline) — for a solo scope this sequencing is still defensible (offline LOD is much cheaper to build correctly than a full meshlet/Nanite-style runtime system), but the plan should be explicit that it is choosing the simpler, more dated-looking path deliberately, not because meshlets are still bleeding-edge. (3) M7's clustered-Forward+-first sequencing, with MegaLights-style stochastic many-light rendering absent from the whole roadmap, is the single clearest "circa-2020" gap: Epic, and independently HypeHype, have already made stochastic direct lighting with many shadowed dynamic lights a shipped, documented pattern, not speculative research — the roadmap should at least name this as a considered-and-rejected alternative rather than not mention it. (4) Nowhere does the roadmap mention ML upscaling evolution (transformer-based DLSS, PSSR2) or frame generation as anything beyond MetalFX's existing device-vendor integration, which is reasonable given no Metal equivalent to DLSS's frame-gen exists, but the roadmap should say so explicitly given how central frame generation has become industry-wide by 2026. Given this is a solo, portfolio-scoped Metal-4-only project, the overall judgment is that M7–M11 correctly avoids overreaching into neural-rendering/transformer-upscaling territory (which has no Metal-native path anyway) while slightly under-selling how mainstream GPU-driven culling and meshlet geometry already are — the fix is sequencing/framing, not a wholesale rewrite of the plan.
