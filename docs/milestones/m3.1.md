# M3.1 — Audited Engineering Baseline

**Status**: Implemented (2026-08-10)

M3.1 turned the migrated renderer into the maintained Luminex baseline. Engine asset failures now
use Engine-owned errors; the scene catalog has stable lowercase IDs and one descriptor table; glTF
loading follows the active-scene dependency closure and uploads shared images with the correct
color-space view. Metal render passes carry capture-readable labels, the device implementation is
split by responsibility, and the Dear ImGui texture removal path uses a pinned public extension
instead of backend-layout access.

Project conventions now define ownership, graphics contracts, comments, documents, commits,
branches, and validation. Every named `.cpp` function has the canonical 120-character boundary.
Clang-backed layout checks and repository policy checks run in CI. Completed execution ledgers and
closed backlogs are absent from the maintained tree; current architecture, guides, milestone
records, frozen research, and the directional roadmap each have a defined lifecycle.

## Evidence

- Debug and Release builds, CPU tests, GPU smoke tests, Metal validation, formatting, policy, and
  standalone Dear ImGui backend-header compilation passed.
- GPU coverage loads and renders the fetched Sponza and Damaged Helmet scenes; scene catalog and
  CLI tests lock Sponza as the default, both lowercase scene IDs, and screenshot-mode parsing.
- Sponza setup now verifies the official 78 MB OBJ+PNG archive from Morgan McGuire's Computer
  Graphics Archive and deterministically converts it to core glTF locally. The archive's `info.js`
  records CC BY 3.0 and © 2010 Frank Meinl/Crytek; the public notices preserve both the attribution
  and the archive citation.
- The public 1280×720 gallery captures were regenerated with the code-generated neutral cubemap.
  SHA-256: Sponza `0e0d3371c852e3cbc91a47abd2f5a030d0e3237f1f69cd234166872208da8a56`;
  Damaged Helmet `7aaa5eae39ae5b4d8bbb616ffff3f64615185a7ed7343b2551b69601871629a7`.
- On an Apple M3 Max with a Debug build and Metal validation, five Sponza startup runs improved
  from a 6.53-second representative baseline and roughly 545 MB RSS to a 3.04-second median and
  393.1 MB maximum RSS. The comparison uses the application binary directly from its build
  directory.

## Deliberate limits

Sponza is the runtime default and portfolio showcase. Its converted archive now meets the 400 MB
startup gate, but synchronous decode and upload still block the window before it becomes responsive.
Asynchronous staging, a loading/error/retry UI, bounded upload batching, and production mip/texture
packaging remain future work. Metal remains the only backend; the RHI continues to grow from
renderer needs rather than speculative parity with another API.
