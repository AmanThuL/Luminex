# M1 — Foundation

**Status**: Implemented (2026-08-07)

M1 replaced the disposable Premake/Vulkan bootstrap with a C++23 xmake project, SDL3 windowing,
Metal 4 through metal-cpp, Slang-to-MSL shaders, Catch2, formatting, CI, and the first thin-RHI
triangle.

Durable decisions are ADRs 0001–0004 and D1–D10 in the accepted upgrade design. The runtime MSL
compiler remains the fallback when the optional offline Metal toolchain is absent.

Evidence at close: Debug and Release builds, unit tests, validation-clean triangle rendering, and a
captured M1 image. Known limit: Metal is the only backend; the RHI intentionally contains only the
contracts exercised by the triangle.
