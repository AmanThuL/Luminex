# R3.7 — Tests and architecture pages

**Status**: Accepted

Implementation authorized on 2026-09-23. The [executor plan](../../plans/2026-09-23-r3.7-tests.md)
is In progress. Design approved by the owner on 2026-09-23. R3.7 gives `Tests/` the second level Source already has,
merges the test helpers defined more than once, and replaces the single 300-line architecture page
with one page per subsystem behind an index. No source file, shader, target, test tag or test case
name changes behaviour or identity; the renderer builds from the parent's inputs at every commit
but one, whose changes are comments.

[Part III](../../roadmap/codebase-restructuring.md#r37--tests-and-architecture-pages) owns the
outcome and the exit gate. [R3](r3.md#r37--tests-and-architecture-pages) owns the series design.
This record keeps the inventory, the placement rule and its path table, the splits, the helper
merges, the page set, the commit sequence and the rules the executor follows. It is delivered as
one pull request.

## Owner decisions, 2026-09-23

| Topic | Decision |
|---|---|

## Rules

- **Input identity.** Every commit except 42 leaves `Source/`, `Shaders/`, `RojoRHI/`, `xmake/`,
  the root `xmake.lua`, `Benchmarks/` and `Tools/TextureBake/` byte-identical to the parent; the
  gate fails on any difference. Commit 42 instead proves every changed file under those paths
  equal to the parent once comments are removed, and generated MSL equal without `#line`.
- **Cheap gate, every commit:** all five targets build; generated MSL equals the parent's; the full
  test inventory (explicit `*` listing, name and tag pairs, including hidden cases) equals the
  parent's for both binaries, with no additions allowed; both CPU suites pass; every root checker,
  both Python suites and `xmake format --check` pass.
- **Split proof, 37–41:** each moved `TEST_CASE` block, from its macro line to its closing brace,
  is byte-identical to its parent text, and the union of the parts' cases equals the original
  file's.
- **GPU gate** after 36, after 41 and at the head: full `Tests` and `RojoRHITests` GPU suites under
  `MTL_DEBUG_LAYER=1`, both checkpoint A filters, `check_checkpoint_a.py` and `xmake policy`.
- The R1 protocol's image, graph, capture and parity comparisons do not run: with the renderer's
  inputs identical, they would measure the parent against itself. This is the owner's narrowing
  for R3.7 only.
- No test tag, case name, section name, CLI option, schema, file format or label changes.
  `RojoRHI/` is not edited. No class, test framework feature or checker rule is added.

## Limits

42 cases stay in a folder other than their subject's, listed above; a future split of those files
needs no new rule. The six RojoRHI-subject cases stay in Luminex until `rojo-rhi` takes them.
The pages describe current behaviour; they do not replace the milestone records' evidence.
Milestone records keep the flat test paths they cite.
