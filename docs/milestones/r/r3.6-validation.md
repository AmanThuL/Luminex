## App-specific observations

Every move touching Shell/Workspace passes a whole-file schema-3 workspace
roundtrip; isolated verifiers run this for every assigned move. A24 and the head
also load a real parent-produced nondefault save: 125% UI scale, visible
Performance/Render Graph windows and explicit detached bounds. Both candidate
re-saves are byte-identical. The original user workspace bytes are restored.

ImGui stores the current civil date in `LastUsed`. After midnight, the gate writes
a new date-scoped reference using the same hash-verified frozen parent executable
and proves its own fresh/reload equality first. It never changes old references
or normalizes candidate bytes. Collection crossing midnight fails and is retained.
`workspace-retrospective-validation-A-head.json` separately audits all 79 completed
workspace logs available at A24, including A2's original parent-reload log. Each
records Metal validation enabled and frame-loop completion, with no recorded
error, warning or assertion. Their byte hashes and the earlier audit are retained;
this retrospective scan is distinct from the later head run.

The schema-4 measurement gate compares keys, types, frame and pass-array counts;
run-varying values are excluded, so it supplies no timing/performance conclusion.
The Console gate compiles the actual panel and sink with deterministic timestamps
and observes ImGui text output across six levels, filtering, Freeze, Clear and
entry/byte eviction. It checks real sink forwarding and visible rows after Clear;
this is a scripted UI context, not an editor screenshot or manual visual review.
