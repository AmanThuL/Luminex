## Coverage before R4.1

The strict parity matrix renders `ScenePass` alone. Screenshots leave auto-exposure off and no
flag turns it on, so `ScenePassAuto` and `ScenePassAutoMask` never render there. Sponza, Damaged
Helmet and MaterialLab carry no `MASK` material, so `ScenePassMask` never renders either. San
Miguel (97 masked materials) and VisibilityLab are the scenes with masked surfaces. Temporal Off
uses the `vertexMain`/`fragmentMain` pair; Native TAA and MetalFX use the motion pair.

## Branches

All three start from `main` at `aa9db9b`.

- `exp/r4.1-harness`, one commit **H**, is the parent build. It changes no shader. In headless
  screenshot mode `LMX_EXPERIMENT_AUTO_EXPOSURE` sets `SceneView::autoExposureEnabled` and seeds
  the exposure buffer on frame zero; `LMX_EXPERIMENT_PIPELINE_LOG` logs, each frame, whether the
  Auto and motion pipelines were selected and how many opaque and masked draw runs the scene pass
  encoded. H also adds `Tools/Experiments/R4_1/` with the session driver and the static comparison.
- `exp/r4.1-candidate-a` and `exp/r4.1-candidate-b`, one commit each on H, change only
  `Shaders/Passes/Scene/ScenePass*.slang` and add `ScenePassShared.slang`. `Sky`, `SkyAuto`,
  `ShadowPass`, host code, labels, bindings and uniform layouts are unchanged.

## The shared module

`Shaders/Passes/Scene/ScenePassShared.slang` is family-local and has no entry point. It holds
everything the four files share today: `Vertex`, `PassUniforms`, every global except
`gExposureOverride`, both vertex-output structs, vertex shading, the motion helpers and the surface
shading body with its comments. Each entry file keeps its name and its four entry points
(`vertexMain`, `fragmentMain`, `vertexMainMotion`, `fragmentMainMotion`); masked entries keep their
`SV_IsFrontFace` parameters, and only the Auto files declare `gExposureOverride` at buffer slot 3.

- **Candidate A, interface generics.** The body is
  `shadeSurfaceDetailed<E : ISceneExposure, C : ISceneCoverage>(input, frontFace)`.
  `ManualExposure` reads `gPass.preExposure`; `AutoExposure`, declared in the Auto files, reads
  `gExposureOverride[0]`. `Opaque` and `Masked` supply the alpha cutoff, the two-sided normal and
  the output alpha. Slang resolves both choices by specialization before emitting MSL.
- **Candidate B, value parameters.** The body is
  `shadeSurfaceDetailed(input, frontFace, float preExposure, bool masked)`, and each entry passes
  its exposure expression and a literal `masked`.

B is adoptable only if no variant's generated MSL still carries the `masked` parameter or a test
of it, meaning Slang folded the constant. Otherwise B keeps a runtime coverage branch, which R4's
boundary forbids, and stays evidence only. A cannot carry that branch.

## Measurement

Every build is a release build on one Apple M3 Max in one session, from its own worktree.

**Static comparison**, per variant and candidate against H, with slangc run with the build rule's
arguments plus `-reflection-json`:

- generated MSL with `#line` directives dropped; every differing line is listed in the evidence and
  summarized in the validation record;
- reflected resource layout: the JSON's parameters sorted by name and its entry points must be
  deep-equal; a raw ordering difference is reported;
- MSL entry signatures: the multiset of `[[buffer(n)]]`, `[[texture(n)]]` and `[[sampler(n)]]`
  arguments with their types, per entry point, must be equal;
- for B, a scan for the `masked` parameter or a test of it in each variant's MSL.

**Rendered parity.** The 15 cases of `Tools/Screenshots/reference.json`, plus auto-exposure on for
sponza, damaged-helmet, material-lab, san-miguel and visibility-lab at `off` and `taa` scale 1
(10 cases), plus manual exposure for san-miguel and visibility-lab at `off` and `taa` scale 1
(4 cases). Each capture is a fresh process with `parity.py`'s command: 1280×720, 32 frames, BMP,
`MTL_DEBUG_LAYER=1`, `LMX_SCREENSHOT_NO_BLOOM` unset. Each of the 8 rounds runs every case once on
each build, the build order rotating by round (H,A,B; A,B,H; B,H,A; ...). All 8 rounds run; the cap
is not extended. A case is unchanged for a candidate when every hash that candidate produced also
occurred from H in the session. The 15 established cases also report their match against
`reference.json`, for information only; that file and the M6.5 exception stay as they are.

**Coverage.** H's pipeline log, captured for every H capture, must show for each extension case the
selection the case claims (Auto on or off, motion on or off) and more than zero masked draw runs
for san-miguel and visibility-lab. Each of the eight variant and entry-pair cells must be rendered
by at least one case, or the comparison is incomplete.

**Suites.** On H, A and B: `xmake test Tests/unit`, and `MTL_DEBUG_LAYER=1` `Tests [gpu]~[.]` with
equal case and assertion counts and no validation error.

## Decision rule

A candidate passes when all four hold:

1. every variant's reflected layout and entry signatures equal H's;
2. all 29 cases are unchanged under the strict rule, with coverage complete;
3. both suites pass with counts equal to H's and no validation error;
4. its diff from H touches only `Shaders/Passes/Scene/ScenePass*.slang`, the `.metal` inventory
   equals H's plus `ScenePassShared`, and the repository's policy checkers pass.

Adopt A if A passes. Otherwise adopt B if B passes and is branch-free. Otherwise DEFER. The record
names every MSL difference whichever way the decision falls. Adoption is a recommendation for R4.2,
which lands only after the owner accepts it.

## Boundaries

No merged pipeline, runtime exposure or coverage branch, or change to shading, bindings, uniform
layouts, pass or pipeline labels. `TemporalResolve`/`TemporalUpscale`, `Sky`/`SkyAuto` and
`ShadowPass`/`ShadowPassMask` are out of scope. The harness never reaches `main`. A failure is
recorded, not retried until passing; no case is dropped from the matrix after measurement starts.
