## Harness

The cheap gate checks the author identities, then input identity (or, with `--comment-only`, a
proof that every changed file under the identity paths differs from the parent only in comments
and whitespace, using clang's raw lexer). It then builds all five targets, compares generated
MSL, the full inventory of both binaries, the RHI case/tag pairing and the flag carriers, and
runs both CPU suites, the seven root checkers, `check_checkpoint_a.py`, the module link check,
the allowlist, both Python suites and `xmake format --check` (15 independent checks, scheduled
concurrently, every exit status kept). The GPU gate ties itself to its cheap gate's HEAD, tree and
78 binary and shader hashes, then runs both GPU suites and both checkpoint A filters under Metal
validation, `check_checkpoint_a.py` and `xmake policy`.

## Proofs

- **Input identity.** Walking every commit, only step 42 touches `Source/`, `Shaders/`,
  `RojoRHI/`, `xmake/`, the root `xmake.lua`, `Benchmarks/` or `Tools/TextureBake/`. Its nine files
  (four Scene shaders, `Lighting.slang`, `PunctualLightOracle.slang`, `ShadowStage.{h,cpp}`,
  `MaterialLab.cpp`) pass the v5 comment proof, and generated MSL without `#line` equals the
  parent's at every gate.
- **Moves.** `move-ledger-2-34.json` records, for each of steps 2–34, that the commit's tree
  equals the scripted replay of the path table plus its documentation delta; all 33 trees match
  the branch commits.
- **Splits.** `split-proof-v2.py` on each split commit against the file at its parent commit
  passes: `RenderTests` 16 cases in 4 parts, `GpuExposureBloomTests` 10 in 2,
  `GpuRendererLightingTests` 10 in 2, `ScenePlaybackTests` 18 in 2, `SceneTransformTests` 11 in 2;
  every block is byte-identical, none is duplicated and order is preserved
  (`proofs/branch-split-proofs.log`).
- **Tree.** The head holds 135 test sources in 34 folders (largest leaf 12), 906 `TEST_CASE`
  macros, and exactly the 14 `Support/` files, with all 12 headers in the contract's
  `privateHeaders`. Every helper include is `Support/<Name>.h`.
- **Authorship.** All 47 branch commits have the owner as author and committer, with no
  co-author trailer; scopes are `test` and `docs`.

## Rulings and departures from the record

The [design record](r3.7.md) now states the corrected counts and narrowed rules; this section
keeps what changed and why.

- **Counts.** The record said the parent held 130 test sources and the head 137. The parent holds
  128 (the 130 `.cpp` files include `EngineTestSupport.cpp` and `RhiLogListener.cpp`, and only 128
  makes the 143 entries add up); the head holds 135, which the path table itself sums to.
- **Identity after step 42.** The record required every commit except 42 to be byte-identical to
  the parent under the identity paths. Commits 43–45 inherit step 42's comment edits, so that
  literal check fails for them (S43). From step 43 the gate instead runs the comment-only proof
  against `d0c4fed` and requires an empty identity-path diff against step 42 (`641f262`), checked
  before the gate (`S43-r1.identity-vs-42.txt`, `S44…`, `S45…`, all empty). Together these hold the
  intent: the renderer's inputs change only by step 42's comments. The record and the R3 series
  record now read "identical to the commit before it".
- **Frozen links and mentions.** The record said milestone records and ADRs keep their paths.
  The moves rewrote two markdown links so the link check passes at every commit:
  `docs/milestones/m7/m7.2-visibility-followup.md` now points at
  `Tests/Render/Passes/Visibility/GpuVisibilityContributionTests.cpp`, and
  `docs/research/2026-09-06-graphics-paradigm-project-fit.md` at `Tests/Support/BrdfOracle.h`.
  The walkthrough move rewrote plain-text mentions as well as links, in ADRs 0015 and 0017, the
  M6 designs and the R-series records; `r3.1.md` therefore names the new walkthrough path in a
  sentence about its own review. The documentation convention permits path-only changes.
- **Walkthrough.** `frame-pipeline.md` gained a `**Status**` line; to stay within 300 lines two
  paragraphs were rewrapped to wider lines without dropping a word. The budget checker is
  unchanged.
- **Constants copied per part.** `kEps = 1e-5f` is repeated in `EngineCameraTests` and
  `EngineMeshGeneratorTests`, keeping each `near3` call verbatim; `kLuminanceWeights` is repeated
  in `GpuExposureBloomTests` and `GpuBloomTests`, each mirroring its own shader's constant.
- **Golden sites.** Merging the two `goldenPath` bodies into `Support/GoldenFile.h` leaves five
  sites that build `LMX_REPO_ROOT "/Tests/Golden/…"`; no path string changed.
- **Page Tests sections.** Only the seven subsystem pages end with their `Tests/` folders; the
  overview index and the moved walkthrough have none.
- **GPU gates G36 and G41** ran `gpu-v2.sh`, accepted because `gpu-v3.sh` differs only by
  printing script hashes; G45 at the head ran `gpu-v3.sh`.
- **Re-authored commits.** Before any gate or push, a shared repository setting briefly gave
  branch commits a throwaway evidence identity. The setting was removed and the unpushed commits
  were re-authored to the owner; `pre-reauthor-log.txt` and `post-reauthor-log.txt` show every
  tree unchanged, which is why the move ledger's commit hashes differ from the branch's while its
  trees match. The harness now passes any throwaway identity per command only.
- **Commit scope.** Subjects use the `test` scope the commits convention lists, not the plural.
