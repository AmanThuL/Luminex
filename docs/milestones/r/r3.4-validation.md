# R3.4 — Core Validation Record

**Status**: Implemented

`Source/Core/` is now five folders: `Diagnostics/`, `IO/`, `Math/`, `Containers/` and `Util/`. Core
gained bounds accumulation, spheres, frustum extraction and plane rejection, reversed-depth
projection and the orthographic fit, radical-inverse and Hammersley sequences, cube-map and GGX
sampling, generational handles and a slot allocator, dirty sets, intervals, a ring buffer, a
stopwatch and ASCII lowercasing, each with its own test file, and received SHA-256, numeric parsing
and transform decomposition. Asset, Engine and the catalog adopted what they use; Render adopted
the frustum, sequence, fit and ceiling-division math. Engine's `Types/` is divided into `View/`,
`Lights/`, `Geometry/` and `Material/`, `SceneTables.cpp` and `Scene.cpp` are decomposed by
responsibility, and the catalog is its own unit `Source/Scenes` (target `Scenes`, namespace
`lmx::scenes`), reached by Engine through a loader callback only.

Against the [exit gate](../../roadmap/codebase-restructuring.md#r34--core): the per-commit protocol
and the format check held at every code commit; the three Temporal Off screenshots and the Damaged
Helmet bake stayed byte-identical from S16 to S26 and at the head; Core reaches no Engine, Render,
App or RojoRHI header or symbol, and Engine reaches no catalog header or symbol; each new Core
header landed with its tests; every parent test case name, tag and case-to-tag pairing is still
present. Nothing rendered or observable changed: GPU tests, graph dumps, screenshots, capture
sequences, baked textures and the parity matrix match the parent.

Parent for every comparison: `52945a6`, the tip of `main`. The 33 commits were made on branch
`r3.4-chain` from `20db2e5`, the tip of `r3.4-core`, which fast-forwards to it. Head protocol
candidate: `642791b`. Device: Apple M3 Max, macOS 26.7, Metal 4, release builds, xmake 3.0.9.
Dated 2026-09-21.

## The gates

`gate.sh <worktree> <label>` builds `App`, `Tests`, `FrameDataBench`, `TextureBake` and
`RojoRHITests` in release, then:

1. strips `#line` from every `.metal` file of the three shader output directories and diffs them
   against the parent's (189 files, 63 per directory);
2. requires every line of the parent's case list (849 lines), tag list (70 tag names) and
   case-to-tag list, file and line dropped, to remain present; the candidate may add lines;
3. asserts `LocalLightMath.cpp`, found by basename, carries `-ffp-contract=off` exactly once, and
   that the set of files carrying the flag equals the parent's (`LightClusters.cpp`,
   `LocalLightMath.cpp`, `Occlusion.cpp`, `Visibility.cpp`);
4. runs `check_submodule_pin.py`, `check_project_policy.py`, `check_shader_imports.py`,
   `check_source_headers.py`, `check_cpp_layout.py`, the empty-allowlist assertion,
   `check_module_deps.py --link` and `check_cpp_comments.py --public-api-docs error`;
5. runs the `Tools/tests` and `Tools/TemporalCompare` Python suites, `xmake format --check`, and
   the CPU filters of both test binaries.

A passing log ends with the Tests line, `All tests passed (419 assertions in 143 test cases)` for
RojoRHITests, then `GATE PASS <label>`. At the parent the Tests line is `903868 assertions in 650
test cases`.

`heavy.sh <worktree> <label>` builds `App` and `TextureBake`, captures `sponza`, `light-lab` and
`temporal-lab` with `--temporal off --frames 4` and `cmp`s each BMP against the parent's, then bakes
a fresh copy of `DamagedHelmet.glb` with `bake_gltf_textures.py` in the form `xmake/setup.lua` uses
and `diff -rq`s the DDS and manifest against the parent's. The parent references were captured
twice and compared before being frozen. `scenes.sh <label>` captures `material-lab`,
`visibility-lab`, `damaged-helmet` and `san-miguel` the same way from the parent and the chain
worktree and `cmp`s them; it covers the non-constant IBL path and the labs the heavy gate does not.

The gates were proven to fail before use, on a scratch worktree of the parent: a renamed test case
fails the inventory check naming it (`probe-case`), a removed case fails naming exactly that line
(`probe-removed`), two added cases, one under a new tag, pass (`probe-add-only`, 652 cases), the
flag spreading to `Camera.cpp` fails the carrier check (`probe-ffp-spread`), and a narrowed field
of view fails the heavy gate at the Sponza screenshot (`probe-fovy`). The parent passes both
against itself (`parent-self`, `parent-self2`, `parent-self3`).

Two gate defects were found in review and fixed before any chain commit was judged. `sort` and
`comm` collated under the shell's UTF-8 locale while the case-to-tag list was sorted by code point,
so `comm` exited non-zero on an add-only candidate; the scripts now export `LC_ALL=C` and read
`comm`'s output rather than its status. `--list-tags` prints a per-tag count, so a new case under an
existing tag read as a lost line; the tag list now keeps names only. The parent's three inventory
files were regenerated by hand with the fixed commands, the originals kept as `*.pre-fix`; the
regenerated lists hold the same 849 cases and 70 tag names. One early run at S3 (`S3-early`) used
the unfixed script; S3 was gated again as `V-S3`.

## Deviations from the record

- **S16 is two commits.** SHA-256 was extracted by hand from `TextureBake.cpp`'s anonymous
  namespace (`ee0d20c`); `Parse.h` moved by script (`ea88218`, step S16b). The heavy gate ran on the
  first and on S17, not on S16b alone, which moves one header.
- **The flag assertion is set equality.** The record's "`LocalLightMath.cpp` only" does not hold at
  the parent, where `Visibility.cpp`, `Occlusion.cpp` and `LightClusters.cpp` carry the flag. The
  gate requires the carrier set to stay the parent's, which catches the flag leaving a file or
  spreading to one.
- **One test case lands outside the new test files.** The loader-callback case is in
  `Tests/EngineSceneTests.cpp`, beside the scene's other load cases; it is a GPU case.
- **`RetiringBuffer` is in `PacedTable.h`,** not `SceneStorage.h`: `reserveTable` needs the complete
  type and `SceneStorage.h` includes `PacedTable.h`, so the listed placement is circular.
- **`SceneEnvironment.h` is public.** The record lets scenes depend on engine, and the labs attach
  environments through it.
- **Engine's build glob kept `Catalog/*.cpp` until S28.** The catalog still compiled into Engine at
  S26; no Engine source outside `Catalog/` named it.
- **The cheap gate ran at each wave's base during the chain** (S6, S15, S17, S23, S25, S26, S32)
  and on each candidate of S16 and S18–S26; S2–S5 and the nine additive header commits S7–S15 were
  gated individually only afterwards, as `V-` runs. A gate run takes minutes and cannot share a
  worktree.
- **The namespace script's final check ran on the chain** between S28 and S29, since S28 is the
  first tree it applies to.
- **AGENTS.md's R3.4 "implemented" clause is not in S32;** it lands with the closure commits, dated
  after this evidence.

## Limits

- Temporal modes are compared only by the head's parity protocol; the heavy gate captures Temporal
  Off, so the jitter change at S23 was not byte-checked per commit. The Core sequence test pins
  `radicalInverse` bit-exactly and the removed and Core bodies are identical.
- The heavy scenes use a constant neutral environment, so the cube-map area element, the
  out-of-face cube tap and the source-LOD paths of the IBL bake rest on the `material-lab` and
  `san-miguel` screenshot comparisons and the existing IBL tolerance tests.
- `allMatched` against `reference.json` is `false` on both sides, a historical failure.
- Left for the slices that adopt them: `Interval`'s free-function names, a `constexpr` and
  `[[nodiscard]]` pass over Core, a hash for `Handle`, and a per-unit namespace policy check.
- The Core tests compare with `==`, which does not distinguish `+0` from `-0`.
- The mechanical commit bodies cite scripts that live only in the evidence bundle. The bundle is a
  local, untracked directory of the evidence checkout, not yet a verified Drive archive group; see
  the [evidence archive](../../guides/evidence-archive.md) for custody and recovery.
