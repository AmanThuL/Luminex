# M2 — Renderer Skeleton

**Status**: Implemented (2026-08-07)

M2 established `Render`, mesh/camera/uniform plumbing, depth testing, an offscreen scene target, the
docked ImGui editor shell, a viewport texture handoff, explicit render-target transition, and a
three-frames-in-flight resource model.

The stable boundary is a Render-owned frame description consumed through RHI contracts; backend
types stay below RHI. The editor viewport, resize path, camera controls, and GPU capture became part
of the normal run loop.

Evidence at close: CPU tests, GPU smoke tests, Metal validation, resize/camera interaction, and the
M2 scene image. Known limits were deliberate: no asset pipeline, materials, shadows, or general
render graph.
