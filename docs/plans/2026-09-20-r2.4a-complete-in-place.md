# R2.4a — Complete RojoRHI in Place Implementation Plan

**Status**: In progress

> Executors: use superpowers:subagent-driven-development. Steps use checkbox syntax for tracking.
> Task 1 sets this plan to `In progress`. [Plan R2.4b](2026-09-20-r2.4b-extract-and-mount.md)
> follows after this plan's pull request merges and the owner has tagged its head.

**Goal:** `RojoRHI/` owns its formatter settings, ignore rules and source policy, and Luminex
reaches nothing private inside it, so that extraction is a purely mechanical step.

**Architecture:** one Luminex pull request. The component gains copies of four checkers trimmed to
its tree plus `format`/`policy` tasks loaded by its standalone root only. Luminex's checkers stop
walking `RojoRHI/`; until the mount, `xmake policy` runs the component's checkers by path so
coverage never lapses. The GPU test bootstrap is copied into Luminex's own support header.

**Tech stack:** xmake (Lua), Python 3 `unittest`, clang-format, Catch2, C++23.

**Spec:** [design](../specs/2026-09-20-r2.4-extract-mount-wire-design.md), stage 1, under the
[R2 record](../milestones/r2.md#r24--extract-mount-and-wire) and
[ADR 0024](../decisions/0024-rhi-relocation-to-rojorhi.md). Executors read all three and
`docs/conventions/`.

## Global constraints

- No RHI capability or semantic change. No file under `RojoRHI/Include`, `RojoRHI/Source` or
  `RojoRHI/Backends` changes in this plan. No test case is added, renamed or removed in either
  C++ binary.
- Copies, not shared code: the component's checkers import nothing from Luminex's `Tools/`.
- In a Luminex worktree pass `-P .` to every xmake command, copy the `ThirdParty` subdirectories
  rather than the directory, link `Assets/Fetched`, and run checkers directly (`AGENTS.md`).
- Commit subjects follow `docs/conventions/commits.md`: ≤ 72 characters, no trailer, no AI
  attribution in commits or the pull request. Repository-relative paths only in documents.
- Tell every subagent: no helper agents, no lingering monitors, no pushes.
- Models: Opus for Tasks 3–4; Sonnet for Tasks 2, 5, 6; the Opus main thread reviews Sonnet
  work. Opus work has no higher reviewer in this session, so Task 4 ends at an **owner
  checkpoint**. Three failed attempts at one gate: stop, record what failed, report to the owner.

## Gate set G (every commit, from the worktree root)

```bash
xmake f -m release -y -P . --ccache=n && xmake build -P . \
  && xmake build -P . Tests && xmake build -P . RojoRHITests
MTL_DEBUG_LAYER=1 xmake test -P . && python3 Tools/check_checkpoint_a.py
xmake project -k compile_commands -P .
for c in Tools/check_project_policy.py Tools/check_module_deps.py Tools/check_source_headers.py \
  RojoRHI/Tools/check_rhi_headers.py Tools/check_cpp_layout.py Tools/check_shader_imports.py \
  RojoRHI/Tools/check_project_policy.py RojoRHI/Tools/check_shader_imports.py
do python3 "$c" || exit 1; done
python3 Tools/check_cpp_comments.py --public-api-docs error && python3 Tools/check_module_deps.py --link
python3 RojoRHI/Tools/check_cpp_layout.py --compile-commands compile_commands.json \
  && python3 RojoRHI/Tools/check_cpp_comments.py --compile-commands compile_commands.json \
    --public-api-docs error
python3 -m unittest discover -s Tools/tests && python3 -m unittest discover -s Tools/GpuDebug/tests \
  && python3 -m unittest discover -s RojoRHI/Tools/tests -t RojoRHI
xmake format --check -P .
```

Case inventory: in each test binary's build directory run `<binary> --list-tests --reporter xml`,
reduce to sorted `<Name>` values, and require both lists byte-identical to the parent's. Evidence
goes to `../Luminex-evidence/r2.4/<task>/`.

```lua
task("format")
    set_menu {usage = "xmake format [--check]", description = "clang-format all sources",
              options = {{nil, "check", "k", nil, "check only, do not modify"}}}
    on_run(function ()
        import("core.base.option")
        local args = {"-style=file"}
        table.insert(args, option.get("check") and "--dry-run" or "-i")
        if option.get("check") then table.insert(args, "--Werror") end
        for _, root in ipairs({"Include", "Source", "Backends", "Tests", "Tools"}) do
            for _, f in ipairs(os.files(root .. "/**.h")) do table.insert(args, f) end
            for _, f in ipairs(os.files(root .. "/**.cpp")) do table.insert(args, f) end
        end
        os.execv("clang-format", args)
    end)

task("policy")
    set_menu {usage = "xmake policy", description = "check repository and C++ layout policy"}
    on_run(function ()
        os.execv("python3", {"Tools/check_project_policy.py"})
        os.execv("python3", {"Tools/check_shader_imports.py"})
        os.execv("xmake", {"project", "-k", "compile_commands"})
        os.execv("python3", {"Tools/check_cpp_comments.py", "--public-api-docs", "error"})
        os.execv("python3", {"Tools/check_rhi_headers.py"})
        os.execv("python3", {"Tools/check_cpp_layout.py"})
    end)
```
