## A0 findings (2026-09-12)

Apple M3 Max, macOS 26.5.2, Xcode 26.6; pinned metal-cpp macOS26.4 headers.
The standalone probe lives outside the repository and is not production source.

- `supportsMetal4FX` is true. Apple reports content scale bounds **1 to 3**, expressed as
  output/input. The RHI contract remains input/output: expose reciprocal bounds (1/3 to 1),
  and invert and exchange descriptor bounds when creating MetalFX. Passing 0.5 to Apple's
  minimum instead caused `Downscaling is not supported` during creation.
- A carrier barrier without a scaler fence reaches an internal assertion:
  `_outputTextureBarrierStages not set`. Use the public scaler `fence` property. A short
  carrier compute encoder consumes pending queue dependencies, updates the fence at compute/copy
  stages, and ends; MetalFX waits/updates that fence. The next consumer waits on the fence before
  reading output. This path encoded and completed with `MTL_DEBUG_LAYER=1`.
- Required usage values: color/depth/motion/reactive = 1 (`ShaderRead`); output = 7
  (`ShaderRead | ShaderWrite | RenderTarget`). Output storage is private.
- Registering the six application textures and upload/readback buffers in the queue residency set
  was sufficient for the probe; no private MetalFX allocations were registered by application code.
- The public scaler has no label setter. Label its owned fence and wrap encoding in a labeled
  command-buffer debug group; preserve MetalFX's internal encoder labels.
- Initial synchronous creation measured 589.030 ms; four subsequent process samples measured
  154.626, 155.161, 160.212 and 164.605 ms. These are observations, not a performance claim.
- With constant half-float 0.5 color, the 160×90 content rectangle reconstructed 320×180 output:
  first pixel `3801,3801,3801,3c00`, nonzero and approximately (0.5,0.5,0.5,1).
- A GPU capture completed. Runtime evidence for full rendering, overlap, resizing and packing
  remains part of C–E; this small probe does not establish image quality or exposure semantics.

## Integration corrections

These findings resolve the design's open A0 questions. The public API shape stays as specified;
backend implementation translates the reciprocal scale units and uses the fence alternative.
Creation returns null without an NSError parameter, so report contextual creation failure without
inventing an upstream error message. The existing resource wrappers unregister on destruction;
the scaler therefore needs explicit retained per-frame ownership to satisfy its promised retirement.
