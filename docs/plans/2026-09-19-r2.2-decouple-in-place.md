# R2.2 — Decouple In Place Implementation Plan

**Status**: In progress

> Executors: use superpowers:subagent-driven-development. One commit per task unless stated.

**Goal:** `RHI/` builds and tests as if it were already alone — no `Core` dependency, its own test
target, shaders, tools and standalone xmake root — while still inside Luminex.

**Architecture:** a private base in `RHI/Source/Base/` replaces four Core headers and reports
through one public message callback; RHI-only tests and smoke shaders move under `RHI/`; a root-only
`RHI/xmake.lua` plus an includable `RHI/xmake/targets.lua` serve both `xmake -P RHI` and Luminex.

**Spec:** [R2 record](../milestones/r2.md#r22--decouple-in-place) under
[Part III](../roadmap/codebase-restructuring.md#r22--decouple-in-place), bounded by
[ADR 0024](../decisions/0024-rhi-relocation-to-rojorhi.md). Executors read all three. RojoRHI's
founding documents live in the sibling checkout `../rojo-rhi` on branch `foundations`.

## Global constraints

- No rename: namespace `lmx::rhi`, macros `LMX_ASSERT`/`LMX_LOG_*`, include root `RHI/`, targets
  `RHI`/`RHIMetal4ImGui` and every `lmx.*` label stay. R2.3 renames; R2.2 only relocates.
- No RHI capability or semantic change. The only public addition is `RHI/Include/RHI/Message.h`.
  Assertion text `ASSERT FAILED: {cond} ({file}:{line}) — {msg}`, `std::abort()` in every build
  mode, alignment contracts and every log string are unchanged.
- No shader, uniform layout, pass label, schedule or `SceneView` change. Moved test files change
  only include lines; case names, tags, assertions and tolerances are untouched.
- One move per commit, moves separate from edits (`git mv`, then a second commit if content must
  change). Every commit builds, passes `xmake format --check`, `xmake policy`, `python3 -m unittest
  discover -s Tools/tests`, both unit groups and both `MTL_DEBUG_LAYER=1` GPU groups.
- In a worktree pass `-P .` to every xmake command, copy `ThirdParty/`, link `Assets/Fetched`, and
  run the checkers directly (see `AGENTS.md`, Commands).
- Commit subjects follow `docs/conventions/commits.md`: convention scope, ≤ 72 characters, no
  trailer, no task or tool identity. Repository-relative paths only in files.
- Accepted ADRs are not edited. Checkers use the standard library; exit codes 0/1/2 as today.

## Evidence protocol (every task ends with it)

Bundle root: `../Luminex-evidence/r2.2/<task>/`, outside the source tree. Parent = the previous
commit built in a second worktree in the same session on the same device, release mode.

- **Tier 1, every commit:** the gates above, plus the case inventory: run `--list-tests` on every
  test binary of parent and candidate, reduce to sorted case names, and require the candidate union
  to equal the parent union plus the additive cases the task names. Save both lists and the diff.
- **Tier 2, when the SHA-256 of the `App` binary or of any file in `App`'s `Shaders/` output differs
  from the parent:** byte-identical `LMX_GRAPH_DUMP` for Sponza, a capture manifest and tagged PNG
  metadata; `Tools/GpuDebug/gputrace_dump.py` semantic equality (labels, order, uniform layouts;
  timings excluded); and `Tools/Screenshots/parity.py --app <binary> --output <json>` alternating
  parent/candidate for a fixed maximum of 8 rounds. A case is unchanged when every candidate hash
  also occurred from the parent in the session; a candidate-only hash is unresolved and blocks the
  commit. No retry until passing, no re-baseline, `reference.json` untouched.
- When the hashes are equal, record the two hash lists as the proof and skip tier 2.

Expected tier 2 tasks: 2 and 3. Any other task whose `App` hash changes stops and reports.

## Task 2 — Private base and message callback (additive)

**Model**: Opus 5 (review: Fable). **Files**: create `RHI/Include/RHI/Message.h` and, in
`RHI/Source/Base/`, `Assert.h`, `Log.h`, `Align.h`, `Json.h`, `Json.cpp`, `Message.cpp`; modify
`RHI/Include/RHI/RHI.h` (include `Message.h`), `RHI/xmake.lua` (`add_files("Source/Base/*.cpp")`,
private `add_includedirs("Source")`).

```cpp
// RHI/Include/RHI/Message.h — includes <cstdint> and <string_view> only
namespace lmx::rhi {
enum class MessageSeverity : uint8_t { Info, Warning, Error };
using MessageCallback = void (*)(MessageSeverity severity, std::string_view message, void* user);
/// Installs the process-wide sink; nullptr restores the stderr default. Thread-safe.
void setMessageCallback(MessageCallback callback, void* user);
} // namespace lmx::rhi

// RHI/Source/Base/Log.h — includes <format>, "RHI/Message.h"
namespace lmx::rhi::base { void emitMessage(MessageSeverity severity, std::string_view message); }
#define LMX_LOG_INFO(...) \
    ::lmx::rhi::base::emitMessage(::lmx::rhi::MessageSeverity::Info, std::format(__VA_ARGS__))
// LMX_LOG_WARN -> Warning, LMX_LOG_ERROR -> Error, same form.

// RHI/Source/Base/Assert.h — includes "Base/Log.h", <cstdlib>; same body as Core/Assert.h
#define LMX_ASSERT(cond, msg) do { if (!(cond)) { LMX_LOG_ERROR("ASSERT FAILED: {} ({}:{}) — {}", \
    #cond, __FILE__, __LINE__, msg); std::abort(); } } while (0)
```

`Message.cpp`: a `std::mutex` guards the `{callback, user}` pair; `emitMessage` copies the pair
under the lock and calls outside it; with no callback it writes `[RHI] [info|warning|error]
<text>\n` to stderr with one `std::fputs` and `std::fflush`. `Align.h` copies `alignUp` verbatim
(not `alignUpMultiple`); `Json.h`/`Json.cpp` copy `appendJsonEscaped` verbatim, in `lmx::rhi::base`.

1. Build; `RHI/Tools`-bound header check (`python3 Tools/check_rhi_headers.py`) and
   `check_cpp_comments.py --public-api-docs error` stay green with the new public header. Nothing
   calls the base yet, so no test can observe it; Task 3 adds the tests before the swap.

Commit: `rhi: add a private base and a public message callback`
