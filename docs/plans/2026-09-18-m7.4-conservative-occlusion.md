## Implementation details fixed before measurement

- Pyramid dimensions use ceil division of active extents and padded floor-sized Metal mips;
  stop at the first level with both dimensions at most 16. Test every mip directly against
  source depth, including odd extents and active-extent changes without reallocation.
- Freeze `kOcclusionNearGuard = 1e-6f` and `kOcclusionDepthGuard = 1e-5f` before collection.
  Nonfinite projection arithmetic retains the candidate. Near-plane crossings also retain.
  The exclusive rectangle end is ceil(max)+1; convert its last covered pixel (end-1) to a mip
  index, avoiding an accidental extra texel or an out-of-range load.
- The proposed counter sizing contains an arithmetic inconsistency: 11 existing live words
  plus occluded, tested, history-invalid and three geometric retain outcomes requires 17 words.
  Use 20 words per view (17 live + 3 padding), 160 bytes for both views. Ordinary Retained is
  derived from tested minus occluded and the three geometric retain counts. Pin all offsets.
- Preserve the exact source matrix, active extent, camera pose, coverage epoch and generation
  with each declared pyramid. Track source adjacency independently of temporal jitter parity.
  The current and source output extent must agree; projection and render-scale changes retain
  source-space testing. Resize follows the renderer's existing idle precondition.
- Scene coverage tracking compares canonical coverage-affecting data during prepareFrame,
  catches public object/material edits (including masked alpha, diffuse identity and UV transform),
  excludes previousModel/emissive-only changes, and
  publishes a monotonic epoch. Instance identity accompanies retired check data independently
  of row reuse; no Render-to-Scene dependency is introduced.
- Independent reference rendering uses direct per-candidate draws and a private depth target,
  shared masked coverage, exact RGBA byte IDs and declaration-owned identity snapshots.
  Strict unchanged-view runs fail on any visible rejection; moving-view runs fail at streak 2.
  Check observations are keyed to retired frames and never enter rejection decisions.
