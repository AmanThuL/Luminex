## Gate definitions

**Cheap, every implementation commit:** build App, Tests, RojoRHITests,
FrameDataBench and TextureBake; regenerate compilation database; compare generated
MSL with `#line` removed, case/tag/pair inventories and exact flag-carrier set;
run both CPU suites, all root policy checkers including header/comment/layout,
module dependency/link and submodule-pin checks, Python tool suites and format.
No unexpected inventory deletion, rename, retag or addition is accepted.

**Byte, every code change:** three Temporal Off BMPs (Sponza, LightLab,
TemporalLab, four frames), Sponza frame-1 offscreen graph and fresh-workspace
editor graph match parent bytes. Retain raw failures before investigating.

**Workspace, every Shell/Workspace commit:** run the candidate with a copy of
the parent's schema-3 imgui.ini under bounded LMX_MAX_FRAMES; require unchanged
re-saved bytes. Independently compare fresh default saves. Preserve the user's
existing workspace file outside these isolated test runtimes.

**App observations:** B2–B5 structurally compare parent/candidate schema-4
measurement JSON (schema, keys, frame/pass counts; exclude variable measurements)
and scripted Console displayed text. Retain the actual observation method and
limits. B7 repeats measurement structure after timing substitution.

**Full head, each PR:** cheap plus byte/workspace, full GPU suites under
MTL_DEBUG_LAYER=1, both checkpoint-A filters, three-frame sequence/manifest,
validation-clean bounded editor run, xmake policy and AppModel link inspection.
Use the R1 eight-round alternating parent/candidate temporal parity protocol,
fixed before collection. Do not extend its cap or inherit another slice's exception.
Serialize GPU runs so parent/candidate evidence does not overlap.
