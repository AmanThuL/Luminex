# UX6 — Scene authoring implementation

**Status**: In progress
> Execute task by task (subagent-driven-development or executing-plans); steps are checkboxes. Each task writes its tests first, sees them fail, implements, passes the per-commit gates and commits.

**Goal:** deliver the [UX6 record](../milestones/ux/ux6.md) and its [roadmap gate](../roadmap/editor-experience.md#ux6--scene-authoring) as one pull request: lab objects saved in the scene documents, file-authored mobility for objects and lights, and a viewport transform gizmo.
**Architecture:** the document model in `Source/Engine/Asset/Document/` gains immutable shared content (geometry, images) and per-node mesh, motion and mobility; the reader stays on `JsonTokens`, the writer regenerates the geometry buffer deterministically, and a new Engine unit appends document content through the same `Scene::add*` calls the generators use. `SceneSession` owns one pose-lock rule that the Inspector, the session bridge and the gizmo consult. The gizmo is a pure model in `Source/App/Model/Scene/` plus one App translation unit that includes ImGuizmo. Stack: C++23, `asset::JsonTokens`, glm, Dear ImGui, ImGuizmo, Catch2, Python 3, xmake.

## Review focus

1. A schema 2 document whose geometry buffer or an image is missing, truncated or modified fails to load with the JSON pointer of the reference, and the editor keeps the scene it had (Tasks 3, 6).
2. Save As into another directory, then opening the copy with the original deleted, loads the same scene; Save As onto a stem whose texture folder holds foreign files is refused before anything is written (4).
3. Playback starting, a measurement starting, the selection changing or the scene being replaced during a gizmo drag ends the drag; no edit lands on another subject and Escape afterwards does nothing (18, 20).
4. A gizmo scale through zero, a negative scale or a rotation through ±90° pitch leaves a finite pose inside the Inspector's 0.01–100 scale range; no NaN reaches the scene (18).
5. W, E, R, Y, X or Q typed into a text field, during right-mouse look or with a popup open changes no tool; a session proposal that moves a static object is refused with the mobility reason, never `Invalid field` (16, 19).
6. A schema 1 document naming the retired `material-lab` or `temporal-lab` generator fails with a message that names the retirement and schema 2, not `unknown generator` (9).
