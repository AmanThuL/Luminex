# R2.1 — RojoRHI Foundations Implementation Plan

**Status**: In progress

**Goal:** RojoRHI has accepted conventions, founding ADRs and a recorded rename substitution before
any source moves, and Luminex has the ADR that records the relocation.

**Approach:** documents and one data file on an orphan `foundations` branch of `rojo-rhi`; one
ADR and status updates on `docs/r2.1-rojorhi-foundations` in Luminex; one pull request per
repository; every document `Proposed` until the owner accepts.

**Spec:** [R2 milestone record](../milestones/r2.md) (decisions, target shape, R2.1 deliverables)
under [Part III](../roadmap/codebase-restructuring.md#r21--rojorhi-foundations). Executors read both.

## Global constraints

- No source, build or shader file changes in either repository. `rojo-rhi` `main` is not touched.
- Identity, verbatim: namespace `rojoRHI` and `rojoRHI::metal4`; includes `<rojoRHI/Device.h>`;
  macros `ROJORHI_ASSERT`, `ROJORHI_LOG_*`; default label prefix `rojorhi.`; targets `RojoRHI` and
  `RojoRHIMetal4ImGui`; repository `rojo-rhi`; prose name RojoRHI; mount path `RojoRHI/`.
- RojoRHI documents stand alone: a reader with no Luminex checkout can follow them. They name a
  Luminex ADR as provenance by number and title, never by relative link.
- Luminex's accepted ADRs 0002, 0004, 0007, 0009 and 0010 are not edited.
- Every `docs/` file carries `**Status**: Proposed` in its first 30 lines; conventions, guides,
  architecture pages at most 300 lines; `AGENTS.md` and `README.md` at most 250.
- Repository-relative paths only; no home-directory path, personal name, commit hash, task
  identifier or tool identity in any file or commit message. Commits use `docs: <imperative
  outcome>`, 72 characters at most, no trailers.
- The `rojo-rhi` checkout is a sibling of Luminex, written `../rojo-rhi` below. Luminex facts are
  read from `main` at the commit this branch started from.
- License text is "private, all rights reserved"; nothing describes a public release, a second
  backend as a capability, or a command that does not exist yet as current.

## Shared document check

`rojo-rhi` has no policy tool until R2.2. Every task below ends by running this from `../rojo-rhi`;
expected output is `OK`.

```bash
python3 - <<'EOF'
import pathlib, re, sys
errs = []
files = [p for p in pathlib.Path(".").rglob("*.md") if ".git" not in p.parts and "External" not in p.parts]
for p in files:
    text = p.read_text(); lines = text.splitlines()
    budget = 250 if p.name in ("AGENTS.md", "README.md") else 300
    if len(lines) > budget: errs.append(f"{p}: {len(lines)} lines > {budget}")
    if p.parts[0] == "docs" and not re.search(r"^\*\*Status\*\*:", "\n".join(lines[:30]), re.M):
        errs.append(f"{p}: no status field")
    if re.search("/" + "Users/|/" + "home/", text): errs.append(f"{p}: home-directory path")
    for target in re.findall(r"\]\((?!https?:|#|mailto:)([^)#\s]+)", text):
        if not (p.parent / target).exists(): errs.append(f"{p}: broken link {target}")
    root = r"(\w+)/"
    for inc in re.findall(r"#include\s+[<\"]" + root, text):
        if inc.lower() == "rojorhi" and inc != "rojoRHI": errs.append(f"{p}: include root spelled {inc}")
print("\n".join(errs) or "OK"); sys.exit(bool(errs))
EOF
```

## Task 3 — Founding ADRs

**Files:** `docs/decisions/0001-identity-and-naming.md`, `0002-metal4-first.md`, `0003-thin-rhi.md`,
`0004-second-backend-target.md`, `0005-conformance-checkpoint.md`, `0006-execution-model.md`.
**Consumes:** Luminex ADRs 0002, 0004, 0007, 0009, 0010 and the R2 record's decision table.

- [ ] Each file uses `# ADR NNNN: <title>`, `**Status**: Proposed`, a `**Restates**:` line naming the
  Luminex ADR by number and title (0001 has none), then `## Context`, `## Decision`,
  `## Consequences`. Restate only what binds the RHI; write identifiers in their RojoRHI spelling.
- [ ] 0001: the identity table from Global constraints; the case exception and why (`RHI` is an
  initialism, mixed case keeps the word boundary); the include-spelling rule (case-insensitive
  file systems hide a wrong root, so the public-header check rejects any root not spelled
  `rojoRHI/`); rejected `rojorhi`, `rjrhi`, `rojo::rhi`; and this call-site example:

```cpp
// before                                  // after
#include "RHI/Device.h"                    #include <rojoRHI/Device.h>
lmx::rhi::Result<lmx::rhi::Buffer> b;      rojoRHI::Result<rojoRHI::Buffer> b;
LMX_ASSERT(desc.size > 0, "empty");        ROJORHI_ASSERT(desc.size > 0, "empty");
// default label "lmx.buffer.unnamed"      // "rojorhi.buffer.unnamed"
```

- [ ] 0002: `MTLGPUFamilyMetal4` required, no Metal 3 fallback, 3 frames in flight. 0003: public
  headers carry no backend, ImGui or third-party type; creation returns `Result<T>`; misuse is
  `ROJORHI_ASSERT`; every GPU object is labelled; the interface grows only for a consumer's
  demonstrated need; no shader-toolchain duty beyond loading compiled libraries; the one public
  message callback (severity, message; stderr when unset). 0004: D3D12 stays the design target for
  a second backend and is not a capability. 0005: the RHI half of checkpoint A — the case
  inventory RojoRHI owns after the R2.2 split (derive names with
  `grep -rn 'checkpoint-a' Tests` in Luminex, excluding `GpuTransientTests` and
  `RenderGraphTransientTests`), frozen by case name, run with `MTL_DEBUG_LAYER=1`; a future backend
  passes it unchanged. 0006: the execution-model decisions of Luminex 0010 that bind the RHI.
- [ ] Check each restatement against its source sentence by sentence: nothing added, nothing
  dropped that binds the RHI, no Luminex-only concern (render graph, scene, editor) carried over.
- [ ] Run the shared document check; commit `docs: add founding decisions`.
