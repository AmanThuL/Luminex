# M6.1 — Temporal State and Motion

**Status**: Implemented (2026-09-07)

This plan executes the accepted design in `docs/specs/2026-09-07-m6.1-temporal-state-motion-design.md`.
`docs/roadmap.md` owns the M6.1 outcome, deliverables, exit gate, and deferrals; this plan
decomposes that boundary without expanding it. The spec fixes the temporal contract, the motion
convention, the history and reset rules, the attachment growth, the passes, the engine model, and
the testing obligations; tasks reference those definitions and may not change them.

## Outcome

The frame exposes trustworthy camera and rigid-object motion with explicit history ownership:
current and previous transforms, jittered and unjittered matrices, an `RG16Float` motion target
with a declared convention, one Renderer-owned history with derived reset reasons, a deterministic
TemporalLab and a fetched rigid-animation sample, and debug views that show all of it. With
temporal inputs off, the frame declaration and fixed-camera output are byte-identical to M5.5.

## Integration

All work lands on `feat/m6.1-temporal-state-motion`, forked from `main` at the M5.5 baseline, and
reaches `main` in one squash pull request. Tasks 1 and 2 run in parallel on task worktrees under
`.claude/worktrees/` (every xmake command there passes `-P .`; ThirdParty subdirectories are copied
and `Assets/Fetched` linked in) and merge back; Tasks 3 and 4 then run in parallel the same way
(Task 3 consumes Task 2's `MotionClass`, Task 4 consumes Task 1's descriptors); Tasks 5–7 run
sequentially on the outcome branch. Every task passes `xmake format --check`, `xmake policy` (in a worktree:
the checkers run directly), and `xmake test`; GPU checks run on Metal 4 Apple Silicon under
`MTL_DEBUG_LAYER=1`. Parity baselines are the `main` tip's fixed-camera 1280×720 screenshots of
Sponza, Helmet and MaterialLab (SHA-256), taken before Task 5 and kept outside the source tree.

## Global constraints

- C++23; `Result<T>` for creation, `LMX_ASSERT` for misuse; every GPU object labelled.
- RHI growth is additive: no existing public field or signature changes, and every
  `[checkpoint-a]` test source is untouched.
- With `SceneView::temporal.enabled == false`, `declarePasses` declares exactly the M5.5 passes,
  imports and attachments, and the existing pipelines use their original entry points.
- Uniform blocks grow append-only; every `static_assert` size and `registerUniformLayoutsForCapture`
  entry is updated with them.
- The motion convention, sentinel, reset order, and history ownership are the spec's (sections
  3–4); shaders and tests cite `Motion.slang` / `Temporal.h`, never restate numbers.
- New fetched assets keep the `.part` download, per-file SHA-256, license and metadata pattern.
- Commit subjects use the convention scopes, ≤ 72 characters; no AI trailer.

glm::vec2 clipToMotionUv(const glm::vec4& clip);                 // ndc·(0.5,−0.5)+0.5

jittered projection equals `translate(2jx/W, 2jy/H, 0) · projection` and equals the unjittered one
at zero jitter; `inverseViewProjection` round-trips a point; `motionBetween` on a point moved by a
known camera translation and by a known object translation matches the analytic UV delta; the
reset table: none → FirstFrame, off→on → TemporalEnabled, then generation, extents, projection,
cut, none, and the priority when two change at once.

    void animate(double seconds); };

1. `Scene::view()` fills `previousModel` and `motionClass`; `resetMotion`/`commitFrame` snapshot
   `modelMatrix()`; `animate()` writes each track's sampled matrix through `decomposeTransform`
   (a failure is `LMX_ASSERT`, since tracks are validated at load).
2. Loader: read `cgltf_animation[0]`; LINEAR and STEP TRS channels on nodes that reach an active
   instance; bake the instance's world transform at 60 Hz over `[0, duration]` via
   `cgltf_node_transform_world` after writing sampled local TRS; CUBICSPLINE, `skins`, morph
   `targets`, and a non-decomposable baked matrix return `AssetErrorKind::Unsupported`.
3. `xmake setup`: `CesiumMilkTruck.glb`, `LICENSE.md`, `metadata.json` from `helmet_pin`, with
   the spec's `.glb` hash and the license/metadata hashes computed at authoring; the bake step;
   `InterpolationTest.glb` plus license and metadata likewise (no bake). Catalog rows
   `milk-truck` (Sample, `Assets/Fetched/CesiumMilkTruck/CesiumMilkTruck.glb`) and `temporal-lab`
   (Diagnostic, always available).
4. TemporalLab per spec section 8, with numeric placement in the file header: floor 20×20 at
   y = 0 with a generated 8×8 checker texture; rotating cube at (−3, 1, 0), one turn per 4 s; orbit
   sphere radius 2 around a static reference cube at (3, 1, 0), one orbit per 6 s; five poles
   0.05 wide, 3 tall at x ∈ {−1, −0.5, 0, 0.5, 1}, z = −4, oscillating ±0.5 in x over 2 s; an
   `Invalid` cube at (0, 1, 4); camera track: 8 s loop from (0, 3, 10) to (2, 3, 8) with yaw
   drifting ±0.1 rad; `initialCamera` is the track's first key. All keys at 60 Hz.
5. Tests: sampling (lerp midpoint, slerp quarter turn, step held, clamp before/after, wrap);
   `commitFrame` moves `previousModel` and `view()` reports both; loader on
   `Assets/Fetched/InterpolationTest/InterpolationTest.glb` bakes its linear and step clips within
   1e-4 and rejects cubic; a synthetic in-memory glTF with a skin is rejected (skip if fixture
   absent, like the Helmet tests); TemporalLab claims by projected AABB corners.
