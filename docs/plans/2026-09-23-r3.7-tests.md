**Status**: Proposed

> superpowers:executing-plans) task by task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** deliver the [R3.7 record](../milestones/r/r3.7.md) as one pull request of 46 commits:
`Tests/` mirrors `Source/`, duplicated helpers merge into `Support/`, five mixed files split, and

  `RojoRHI/` is never edited. No class, framework feature or checker rule is added.

- Documentation line budgets: README and `AGENTS.md` ≤ 250, every other page and this plan ≤ 300.

checkbox and status updates only. No subagent runs above Opus. GPU work is serialized through
`$EV/gpu.lock`; everything else runs concurrently where the waves allow.

## Self-check before handing off a task

A task is done when its commit exists, its gate log ends with `GATE PASS <label>`, the reviewer
recorded no open finding, and the move ledger or validation notes name the commit and tree.
Failed attempts stay in `$EV`; nothing is retried until passing without a recorded cause.
