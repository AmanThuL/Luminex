# R3.3 Engine Implementation Plan

**Status**: Proposed

> **For agentic workers:** REQUIRED SUB-SKILL: use superpowers:subagent-driven-development to
> execute this plan task by task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `Source/Asset` and `Source/Scene` become `Source/Engine/`, the scene vocabulary leaves
Render, and Render depends on Engine, never the reverse, with no rendered or behavioural change
against `75dd539`.

**Architecture:** the contract first admits both layouts; script-driven commits move one
destination folder each; two extractions and a Render-side builder cut Scene's last Render
includes; target `Scene` dissolves into `Engine`; one token-aware substitution renames the
namespaces. A cheap gate runs at every commit, the full protocol once at the head.

**Spec:** [R3.3 record](../milestones/r/r3.3.md) — its path tables say which file goes where and
its commit sequence numbers (S1–S21) are used below — and [ADR
0025](../decisions/0025-engine-subsystem-and-render-on-engine.md). Executors read both.

## Global constraints

- Branch `r3.3-engine`, in a worktree; the first execution commit sets this plan `In progress`. No
  commit edits a file under `RojoRHI/`. No AI trailer or attribution in commit or pull-request
  text. Subjects follow `docs/conventions/commits.md`: `<scope>: <imperative outcome>`, at most 72
  characters, scopes `engine`, `asset`, `render`, `core`, `tool`, `build`, `docs`; no mention of
  plans, tasks, agents or models.
- No class, file, pass label, shader basename, CLI option, schema, file format, test tag or test
  case name changes; no `SceneView` field change; no using-directive.
- `xmake format --check`, every policy checker, `check_module_deps.py --link` with an **empty**
  allowlist, and the cheap gate pass at **every** commit.
- A mechanical commit (S4–S6, S10–S16, S18, S19) is reproducible: its parent tree plus the recorded
  script plus `xmake format` equals its tree. Hand edits inside one are listed by file and line in
  `$EV/manual-edits.txt` and in the commit body.
- Model tiers: the main thread is Opus 5 and no subagent runs above it. **[Opus]** tasks are
  design-sensitive, **[Sonnet]** standard. An Opus subagent reviews Sonnet work; the main thread
  reviews Opus work.
- Worktree recipe (every agent that builds): every xmake command takes `-P .`; `git submodule
  update --init`; copy each subdirectory of the main checkout's `ThirdParty/` into the worktree's
  `ThirdParty/` (not the directory itself); symlink the main checkout's `Assets/Fetched` to
  `Assets/Fetched`; `xmake f -P . -m release -y`. Never run `xmake policy` in a worktree; run the
  checkers listed in `AGENTS.md` directly.
- Evidence lives in `/tmp/luminex-r3.3-evidence/` (`$EV`), never in the tree. Failed runs are kept.
  GPU work is serialized: one agent uses the GPU at a time. Three failed attempts on one problem:
  stop and report.

### Task 1: Freeze the parent and write the cheap gate [Sonnet]
**Files:** `$EV/gate.sh`, `$EV/parent/` (outside the tree; nothing is committed).
**Produces:** `bash $EV/gate.sh <worktree> <label>` exiting 0 and printing `GATE PASS <label>`, log
at `$EV/gate/<label>.log`; `$EV/parent/{msl,cases.txt,tags.txt,bin/,hashes.txt}`.
- [ ] **Step 1:** worktree of `75dd539` at `$EV/wt-parent` with the recipe; build.
- [ ] **Step 2:** write `$EV/gate.sh`:

```bash
#!/bin/bash
set -euo pipefail  # usage: gate.sh <worktree> <label> [--freeze]
WT=$1; LABEL=$2; EV=/tmp/luminex-r3.3-evidence; OUT=$EV/gate/$LABEL
[ "${3:-}" = "--freeze" ] && OUT=$EV/parent
mkdir -p "$OUT/msl"; cd "$WT"; exec > >(tee "$OUT.log") 2>&1
git rev-parse HEAD
xmake build -P . App Tests FrameDataBench TextureBake
R=build/macosx/arm64/release
for d in Shaders test/Shaders bench/Shaders; do
  for f in "$R/$d"/*.metal; do
    grep -v '^#line' "$f" > "$OUT/msl/$(echo "$d" | tr / _)_$(basename "$f")"; done; done
(cd "$R/test" && ./Tests --list-tests --verbosity quiet | sort) > "$OUT/cases.txt"
(cd "$R/test" && ./Tests --list-tags | sort) > "$OUT/tags.txt"
[ "${3:-}" = "--freeze" ] && exit 0
diff -r "$EV/parent/msl" "$OUT/msl"
diff "$EV/parent/cases.txt" "$OUT/cases.txt"; diff "$EV/parent/tags.txt" "$OUT/tags.txt"
xmake project -k compile_commands -P . >/dev/null
python3 -c "import json; e = [x for x in json.load(open('compile_commands.json')) \
  if x['file'].endswith('LocalLightMath.cpp')]; \
  assert len(e) == 1 and '-ffp-contract=off' in str(e[0]), 'LocalLightMath.cpp lost its flag'"
for c in submodule_pin project_policy shader_imports source_headers cpp_layout; do
  python3 Tools/check_$c.py; done
python3 Tools/check_module_deps.py --link
python3 Tools/check_cpp_comments.py --public-api-docs error
python3 -m unittest discover -s Tools/tests -t . -q && xmake format -P . --check
(cd "$R/test" && ./Tests "~[gpu]")
echo "GATE PASS $LABEL"
```
