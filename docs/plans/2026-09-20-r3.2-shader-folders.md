# R3.2 Shader Folders Implementation Plan

**Status**: Proposed

> **For agentic workers:** REQUIRED SUB-SKILL: use superpowers:subagent-driven-development to
> execute this plan task by task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `Shaders/` becomes `Passes/<family>/`, `Common/` and `Tests/`, with generated MSL
identical to `e9c6e30` once `#line` directives are dropped.

**Architecture:** the build rule and import checker first accept both layouts; eleven
`git mv`-only commits move files; the old layout is dropped; a recorded substitution retargets
comments; documents follow. A cheap gate runs per commit, the full protocol once at the head.

**Spec:** [R3.2 record](../milestones/r/r3.2.md); its path table alone says which file goes
where. Executors read both.

## Global constraints

- Branch `r3.2-shader-folders`; the first execution commit sets this plan `In progress`. No
  commit edits a file under `RojoRHI/`. No AI trailer or attribution in commit or pull-request
  text. Subjects: `<area>: <imperative summary>` (`shader:`, `build:`, `tool:`, `docs:`).
- A move commit contains renames only (`git diff -M --summary HEAD~1` lists only `rename` lines
  at 100%). No import line, pass label, shader basename, CLI option or test name changes.
- `xmake format --check`, the policy checkers and the cheap gate pass at **every** commit.
- Model tiers: the main thread is Opus 5 and no subagent runs above Opus 5. Tasks marked
  **[Opus]** are design-sensitive; **[Sonnet]** standard; **[Haiku]** mechanical. Sonnet work is
  reviewed by an Opus subagent, Opus work by the main thread, Haiku work by Sonnet.
- Worktree recipe (every agent that builds): every xmake command takes `-P .`;
  `git submodule update --init`; copy `imgui`, `metal-cpp`, `slang` and the other subdirectories
  of the main checkout's `ThirdParty/` into the worktree's `ThirdParty/` (not the directory
  itself, which would nest); symlink the main checkout's `Assets/Fetched` to `Assets/Fetched`;
  `xmake f -P . -m release -y`. Never run `xmake policy` in a worktree; run the six checkers
  listed in `AGENTS.md` directly.
- Evidence lives in `/tmp/luminex-r3.2-evidence/` (`$EV`), never in the tree. Failed runs are
  kept, not deleted. GPU work is serialized: one agent uses the GPU at a time.

## Execution waves

| Wave | Tasks | Parallelism |
|---|---|---|
| A | 1, 2, 3, 4, 5 | five agents at once; disjoint files; 2 and 3 each in an own worktree |
| B | 6, then 7 | 6 is serial and fast (main thread); 7 fans out to four verifier agents |
| C | 8, 9, 10 | 8 then 9 commit serially; 10's CPU lanes run beside its one GPU lane |

The main thread cherry-picks Task 2's commit, then Task 3's, and gates both before wave B.

### Task 1: Freeze the parent and write the cheap gate [Sonnet]

**Files:** create `$EV/gate.sh`, `$EV/parent/` (outside the tree; nothing is committed).
**Produces:** `$EV/gate.sh <worktree> <label>` exiting 0 on pass, writing `$EV/gate/<label>.log`;
`$EV/parent/{app,test,bench}/*.metal.norm`, `$EV/parent/<name>.inventory`, `$EV/parent/cases.txt`.

- [ ] **Step 1:** create a worktree of `e9c6e30` at `$EV/wt-parent` with the worktree recipe,
  then `xmake build -P . App Tests FrameDataBench`.
- [ ] **Step 2:** write `$EV/gate.sh`:

```bash
#!/bin/bash
set -euo pipefail  # usage: gate.sh <worktree> <label> [--freeze]
WT=$1; LABEL=$2; EV=/tmp/luminex-r3.2-evidence; OUT=$EV/gate/$LABEL
[ "${3:-}" = "--freeze" ] && OUT=$EV/parent
mkdir -p "$OUT"; cd "$WT"; exec > >(tee "$OUT.log") 2>&1
git rev-parse HEAD
xmake build -P . App Tests FrameDataBench
R=build/macosx/arm64/release
for pair in app: test:test bench:bench; do
  name=${pair%%:*}; dir=$R/${pair#*:}/Shaders; mkdir -p "$OUT/$name"
  for f in "$dir"/*.metal; do grep -v '^#line' "$f" > "$OUT/$name/$(basename "$f").norm"; done
  (cd "$dir" && ls *.metal *.metallib | sort) > "$OUT/$name.inventory"
done
(cd "$R/test" && ./Tests --list-tests --verbosity quiet | sort) > "$OUT/cases.txt"
[ "${3:-}" = "--freeze" ] && exit 0
for name in app test bench; do
  diff -r "$EV/parent/$name" "$OUT/$name"
  diff "$EV/parent/$name.inventory" "$OUT/$name.inventory"
done
diff "$EV/parent/cases.txt" "$OUT/cases.txt"
for c in shader_imports project_policy module_deps source_headers; do
  python3 Tools/check_$c.py; done
python3 -m unittest discover -s Tools/tests -t . -q
xmake format -P . --check
(cd "$R/test" && ./Tests "~[gpu]")
echo "GATE PASS $LABEL"
```

### Task 2: Import checker learns the layout [Opus]

**Files:** modify `Tools/check_shader_imports.py`, `Tools/tests/test_shader_imports.py`.
**Produces:** `check_shaders(root) -> (errors, files, imports)` unchanged in signature. New
module-level `LEGACY = True` switch that Task 8 deletes.

Rules to implement (new layout), beside the existing legacy rules that stay while `LEGACY`:
a module is a file with no `[shader(` under `Common/` or `Passes/<family>/`; a `Common/` module
imports `Common/` only; a family-local module is importable only from `Passes/<same family>/`;
`Tests/` imports any module; entries are never importable; a file directly under `Shaders/` or
deeper than `Passes/<family>/<file>` is an error unless `LEGACY` and it is a root entry or under
`Modules/`; basename collisions stay tree-wide and case-insensitive. Module names stay bare
(`import Lighting;`); the dotted nested-module form is supported under `Common/` only.

- [ ] **Step 1:** add these failing tests to `ShaderImportTests` (keep every existing test):

```python
    def test_family_entries_import_siblings_and_common(self) -> None:
        errors, files, imports = self.check({
            "Passes/Visibility/Classify.slang": '[shader("compute")] void m(){}\n'
                                                "import Visibility; import SceneTables;",
            "Passes/Visibility/Visibility.slang": "import SceneTables;",
            "Common/SceneTables.slang": "float value;",
            "Tests/Probe.slang": "import Visibility;",
        })
        self.assertEqual(errors, [])
        self.assertEqual((files, imports), (4, 4))

    def test_family_local_module_is_private_to_its_folder(self) -> None:
        for importer in ("Passes/Scene/Scene.slang", "Common/Shared.slang"):
            with self.subTest(importer=importer):
                errors, _, _ = self.check({
                    importer: "import Visibility;",
                    "Passes/Visibility/Visibility.slang": "float value;",
                })
                self.assertTrue(any("is local to Shaders/Passes/Visibility" in e for e in errors))

    def test_imports_never_reach_family_entries(self) -> None:
        errors, _, _ = self.check({
            "Passes/Scene/A.slang": "import B;",
            "Passes/Scene/B.slang": '[shader("fragment")] void m(){}',
        })
        self.assertTrue(any("reaches entry point" in e for e in errors))

    def test_files_outside_the_three_folders_fail(self) -> None:
        for stray in ("Passes/Loose.slang", "Passes/Scene/Deep/X.slang", "Other/X.slang"):
            with self.subTest(stray=stray):
                errors, _, _ = self.check({stray: "float value;"})
                self.assertTrue(any("must live in Common/, Tests/ or Passes/<family>/" in e
                                    for e in errors))

    def test_collisions_are_rejected_across_family_folders(self) -> None:
        errors, _, _ = self.check({"Passes/Scene/Dup.slang": "", "Passes/Bloom/dup.slang": ""})
        self.assertTrue(any("duplicate shader output basename" in e for e in errors))
```
