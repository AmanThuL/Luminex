## Roles and parallelism

Main thread (Opus 5.5): worktree, build checks, captures, classification, records. Task 1 is
Sonnet 5, reviewed by Opus 5; the closing records get one Opus 5 review. **W1** Task 1 in parallel
with Tasks 0 and 2 → **W2** Task 3 (stage 2) → **W3** Tasks 4–5.

## Review focus

1. A stage 1 or stage 2 capture that failed (`sha256: null`) makes the stage incomplete; the
   evaluator refuses to classify or score rather than skipping it.
2. The null control and the candidate use the same pool: the seven H images from the other rounds.
3. Argument order is fixed: `image_difference(parent=H_s, candidate=X_r, (1280, 720), "strict")`.
4. The classification the evaluator recomputes must equal the frozen `classification.json`.
5. A non-repeatable case whose null control fails is reported as unmeasurable, never as a pass.

### Task 1 (Sonnet): `Tools/Experiments/R4_1/followup_eval.py` — worktree `followup`

**Produces** (`--selftest` runs in-file unittest; imports `session` from its own directory and
`compare` from `Tools/Screenshots/`):

- `classify(stage1_dir) -> dict[str, str]`: reads stage 1 with `session._read_session(dir,
  truncate_torn=False)`; requires a header with builds `["H"]`, rounds 8, the 29 `session.CASES`
  names, and exactly one non-null capture per (round 0–7, case); raises otherwise. A case is
  `"repeatable"` when its 8 hashes are equal, else `"non-repeatable"`.
- `leave_one_out(case_dir, h_by_round, x_by_round, extent=(1280, 720)) -> list[dict]`: for each round
  r, compares `x_by_round[r]` with `h_by_round[s]` for every s ≠ r using
  `compare.image_difference(parent=H_s, candidate=X_r, extent, "strict")` on
  `<case_dir>/<sha>.bmp`; identical hashes are a pass with zero difference without opening files.
  Each row: round, `pass` (any of the seven passes), nearest s (fewest differing pixels) with
  `differingPixels`, `over8Pixels`, `maxChannelDelta`, and `hashSeenFromH`.
- `evaluate_followup(stage1_dir, stage2_dir, frozen_classification) -> dict`: checks
  `classify(stage1_dir) == frozen_classification`; runs `session.evaluate` on stage 2 for
  completeness, coverage and the hash rule; for each non-repeatable case computes the null control
  (H against H) and A and B; reports per-case `nullHolds`, `aPasses`, `bPasses`, `unmeasurable`;
  and top-level items 2–5 of the spec's decision rule, `power`, `aPassesFollowup`.
- CLI: `--classify STAGE1 --output classification.json` and `--evaluate --stage1 S1 --stage2 S2
  --classification C --output DIR` (writes `followup.json`, `followup.md`; refuses an existing DIR).

- [ ] Selftests first (tiny synthetic BMPs through PIL with a small `extent`): classify rejects a
  null capture, a missing round and a wrong header; repeatable versus non-repeatable; leave-one-out
  excludes the same round (a candidate equal only to H of its own round fails); pass when any of the
  seven passes; parent/candidate argument order; identical-hash shortcut; unmeasurable when a null
  control fails; power false when B passes every non-repeatable case; classification mismatch
  raises. Then implement; `python3 Tools/Experiments/R4_1/followup_eval.py --selftest` passes.
