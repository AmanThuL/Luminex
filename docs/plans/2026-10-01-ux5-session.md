## Review focus

1. A client writes the glTF, then the buffer, then the sidecar: the editor shows one proposal with the client's name, never an "Unknown external change" card followed by a second card (Tasks 5, 8).
2. The editor's own Save, Save As and a Reject followed by Save never raise a proposal against themselves (8).
3. A client that disconnects mid-approval, sends a 2 MiB line, sends invalid UTF-8 or JSON, or omits `hello` gets one error or a clean close; the editor keeps running and the next client connects (12, 14).
4. An evidence name containing `/`, `..`, a leading `.` or nothing is refused before anything is written (12, 18).
5. Quitting or closing the panel's Listen toggle with a pending approval, a running child or a connected client joins the thread, kills and reaps the child, and removes the socket file (14, 18).
