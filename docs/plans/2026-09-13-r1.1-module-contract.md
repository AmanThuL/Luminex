# R1.1 — Module Contract and Enforcement

**Status**: In progress (2026-09-13)

This plan executes R1.1 of the
[Codebase Refactoring](../roadmap/codebase-refactoring.md#r11--module-contract-and-enforcement)
roadmap part, which owns the outcome, deliverables, exit gate and deferrals; this plan decomposes
that boundary without expanding it. The roadmap's
[target module contract](../roadmap/codebase-refactoring.md#target-module-contract) and R1
comparison protocol are the definitions tasks cite and may not change. R1.1 moves no source except
the two ImGui adapter files.

## Outcome

The layering is a convention with a machine-readable contract; a dependency checker reconciles an
explicit ownership map with xmake target membership, resolves includes with each target's
compilation context and follows project includes transitively; link-level checks read declared
closures, linked frameworks and archive symbols; every header under `Source/` compiles standalone;
and an accepted ADR records the layering. On the otherwise unchanged tree every check passes with
an allowlist naming each current violation of the target contract, which R1.2 burns down to empty.

## Integration

Work lands on `feat/r1.1-module-contract`, forked from `main` after the roadmap commit, and reaches
`main` in one squash pull request. Tasks 1 and 2 run first; Tasks 3, 4 and 5 can run in parallel
on task worktrees under `.claude/worktrees/` (pass `-P .` to every xmake command there, copy the
ThirdParty subdirectories, link `Assets/Fetched`, run the checkers directly) and merge back; Task 6
runs on the outcome branch. Every task passes `xmake format --check`, `xmake policy` and
`python3 -m unittest discover -s Tools/tests`. Nothing here changes rendered output, shaders, RHI
headers or graph declarations, so the R1 comparison protocol reduces to `xmake test` green and a
graph dump byte-identical to the parent commit, both recorded in Task 6. The commit that sets this
plan to In progress also points the roadmap entry's baseline sentence at it.

## Global constraints

- Checkers use the Python 3.12 standard library only; exit codes are 0 pass, 1 violation, 2
  could-not-run, like the existing checkers. Comments in `Tools/` follow the process-narration rule.
- `Tools/module_contract.json` is the convention's machine twin: every unit, edge, header
  allowance and third-party name in `docs/conventions/modules.md` appears there and vice versa.
- Unit reach is transitive over project headers; third-party reach is checked on direct includes
  only, because a forbidden library reached through a project header is caught as a forbidden unit.
- Every allowlist entry carries `until` naming the slice that removes it; an unused entry fails.
- Unit names fixed here and used by later slices: `core`, `rhi-public`, `rhi-impl`,
  `metal4-backend`, `imgui-adapter`, `render`, `asset`, `scene`, `app-model`, `app-shell`, `tests`,
  `texture-bake`, `benchmarks`. `asset`, `scene` and `app-model` are file lists inside today's
  directories until R1.2 and R1.3 give them directories.
- Commit subjects use the convention scopes; no AI trailer; ≤ 72 characters.

## Task 2 — Target dump, contract data and ownership reconciliation

**Model**: Opus 5 (review: Fable, main thread). **Files**: create `Tools/xmake_targets.lua`,
`Tools/module_contract.json`, `Tools/module_allowlist.json`, `Tools/check_module_deps.py`,
`Tools/tests/test_module_deps.py`.

`xmake_targets.lua`, run as `xmake lua Tools/xmake_targets.lua`, prints one JSON object as its
last line (single-valued `deps`, `packages` and `frameworks` arrive as strings and are normalised):

```lua
import("core.project.project")
import("core.base.json")
local function list(v) if v == nil then return {} elseif type(v) == "table" then return v end return {v} end
local out = {}
for name, t in pairs(project.targets()) do
    local files = {}
    for _, f in ipairs(t:sourcefiles()) do table.insert(files, path.relative(path.absolute(f), os.projectdir())) end
    table.sort(files)
    out[name] = {kind = t:kind(), files = files, deps = list(t:get("deps")), packages = list(t:get("packages")),
                 frameworks = list(t:get("frameworks")), targetfile = path.relative(t:targetfile(), os.projectdir())}
end
print(json.encode(out))
```

Contract shape (`schemaVersion` 1); the full file lists every current Engine and App model file:

```json
{"units": {"asset": {"paths": ["Source/Engine/Asset.h", "Source/Engine/DdsLoader.cpp"], "targets": ["Engine"],
   "units": ["core"], "headers": ["RHI/Format.h"], "thirdParty": ["glm", "cgltf", "stb"], "note": "R1.2 moves to Source/Asset"},
  "app-shell": {"paths": ["Source/App"], "targets": ["App"], "units": ["core", "rhi-public", "render", "asset",
   "scene", "app-model", "imgui-adapter"], "thirdParty": ["glm", "imgui", "imgui-node-editor", "libsdl3"]}},
 "targets": {"TextureBake": {"deps": ["Core", "Asset"], "frameworks": []}},
 "budgets": {"production": 1000, "tests": 1500}, "roots": ["Source", "RHI", "Tests", "Tools/TextureBake", "Benchmarks"]}
```

Allowlist shape: `{"schemaVersion": 1, "entries": [{"kind": "shared-source", "file":
"Source/App/AppOptions.cpp", "targets": ["App", "Tests"], "until": "R1.3"}]}`; kinds are
`shared-source`, `include` (`file`, `reaches`), `target-dep` (`target`, `dep`), `framework`
(`target`, `framework`) and `header` (`file`). Task 2 commits it empty.

Checker surface this task produces (later tasks add to the same module):

```python
def load_contract(path: Path) -> dict            # validates schema, unit references, existing paths
def load_allowlist(path: Path) -> list[dict]
def load_targets(path: Path | None, root: Path) -> dict[str, dict]   # None runs xmake lua, reads the last line
def owner_of(path: Path, contract: dict) -> str | None                # longest matching path prefix
```

   `shared-source` entry names it; a source whose target is not in its unit's `targets` is an

## Task 3 — Include resolution and transitive reach

**Model**: Opus 5 (review: Fable, main thread). **Depends on**: Task 2. **Files**: modify
`Tools/check_module_deps.py`, `Tools/tests/test_module_deps.py`.

```python
@dataclass(frozen=True) class Resolved: kind: str; unit: str | None; name: str | None; path: Path | None  # project|third-party|system
def include_dirs(entry: dict) -> list[Path]      # -I/-isystem/-iframework, joined or split tokens, relative to entry["directory"]
def context_for(path: Path, unit: str, targets, compile_db, contract) -> list[Path]  # own command, else first source of a unit target
def parse_includes(text: str) -> list[tuple[str, bool]]                              # (spec, quoted)
def resolve_include(includer: Path, spec: str, quoted: bool, dirs: list[Path], root: Path, contract) -> Resolved
def third_party_name(path: Path, root: Path) -> str | None   # ThirdParty/<name> (imgui/backends -> imgui); .xmake/packages/<x>/<name>/...
def check_includes(files, targets, compile_db, contract, allowlist, errors) -> None
```

1. Tests first: a quoted include resolves relative to the includer before the include
   directories (the backend's `"Metal4Common.h"` case); an angle include under a package path
   maps to the package name and under `ThirdParty/imgui/backends` to `imgui`; an unresolvable
   angle include is `system` and ignored; a file whose header reaches a forbidden unit through
   two project headers is reported with the chain; a forbidden third-party reached through an
   allowed project header is not a direct violation; a `headers` allowance admits `RHI/Format.h`
   but not `RHI/Device.h`; an `include` allowlist entry suppresses exactly one violation and an
   unused entry is an error.
2. Implement with a memoised depth-first reach per file; error text is
   `<file>: <unit> reaches <target unit> via <a> -> <b>`. Run on the real tree and confirm the
   violations are only: `asset` files reaching `rhi-public` (`DdsLoader`, `Ibl`, `TextureBake`,
   `HdrEnvironment` through `Ibl.h`, and their sources), `GltfLoader` reaching `render` through
   `Render/AlphaMode.h`, and `texture-bake` reaching `rhi-public` through `Engine/TextureBake.h`.
   Anything else is a finding to report before allowlisting.

Commit: `tool: resolve includes and check transitive module reach`

## Task 4 — Target closure, link phase and review budgets

**Model**: Sonnet 5 (review: Opus 5). **Depends on**: Task 2. **Files**: modify
`Tools/check_module_deps.py`, `Tools/tests/test_module_deps.py`.

```python
def dependency_closure(name: str, targets) -> set[str]
def check_target_closure(targets, contract, allowlist, errors) -> None   # closure minus allowed deps; unknown allowed names tolerated
def linked_frameworks(targetfile: Path, run=subprocess.run) -> list[str]  # otool -L, framework basenames
def undefined_symbols(archive: Path, run=subprocess.run) -> list[str]     # nm -u, demangled through c++filt
def check_link(targets, contract, allowlist, errors, run=subprocess.run) -> None   # only with --link
def report_budgets(files: list[Path], contract, root: Path) -> list[str]  # "review candidate: <file> (<n> > <budget> lines)"
```

1. Tests first (inject `run` returning canned `otool`/`nm` output): a closure containing a dep
   outside the allowed set is an error unless a `target-dep` entry covers it; an allowed name that
   is not a target (such as `Asset` before R1.2) is tolerated; a framework outside the target's
   allowed list is an error unless a `framework` entry covers it; an archive with a demangled
   `lmx::rhi::` undefined symbol fails a target whose contract entry sets
   `"forbidUndefined": "lmx::rhi::"`; a missing target file under `--link` is exit 2, not a pass;
   budgets print candidates and never add errors.
2. Implement; `--link` runs closure, frameworks and archives against `targetfile` from the dump
   and is skipped without the flag. The contract carries no `forbidUndefined` entry yet (R1.2
   adds Asset's); the mechanism is tested here. On the real tree the closure check reports
   `TextureBake` depending on `RHI`, `Render` and `Engine`, and `--link` reports its Metal,
   MetalFX, QuartzCore and Foundation frameworks.

Commit: `tool: check target closures, linked frameworks and archive symbols`
