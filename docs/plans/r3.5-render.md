**Status**: In progress

## Contract and execution

Implement the accepted [design](../milestones/r/r3.5.md) in two pull requests against `main`.
The comparison baseline is `2f37615`; the design commit is `0422622`.
The owner authorized implementation, both PRs, automatic merge after passing checks, and a final
clean local `main` synchronized with `origin/main`. No Superpowers skill is used.
The workflow is written tasks, small implementation commits, focused verification, independent
specification and code review, integration gates, then closure. Parallel work uses disjoint
files or isolated worktrees; GPU evidence runs serially on this device.

Read before execution: R3.3 and R3.4 records and validation, R3 series design, ADR 0026,
engineering/C++/commit/documentation conventions, the founding decisions and R1 comparison protocol.
Preserve labels, shaders, CLI, schemas, SceneView, existing tests and the RojoRHI submodule pin.
VendorTemporalScaler remains the named adapter exception; resize/history policy stays unchanged.
GPU object creation order may change only where the design declares that difference.
