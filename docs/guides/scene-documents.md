# Scene documents

**Status**: Implemented

Luminex opens six catalog scenes from `Assets/Scenes/*.scene.gltf`: Sponza, MaterialLab,
TemporalLab, San Miguel, VisibilityLab and LightLab. MaterialLab includes Damaged Helmet;
TemporalLab includes the animated Milk Truck. San Miguel needs `xmake setup --san-miguel`.
The removed `damaged-helmet` and `milk-truck` IDs are no longer CLI or catalog choices.

## Open a scene

File > Open Scene selects a catalog entry. File > Open… (`Cmd+O`) opens a `.scene.gltf` file
through the native chooser. The same choice works on the command line:

```sh
xmake run -P . App --scene material-lab
xmake run -P . App --scene /absolute/experiments/copy.scene.gltf
xmake run -P . App --scene temporal-lab --temporal off --frames 32 --screenshot /tmp/truck.png
```

An external document still resolves asset URIs relative to the repository's `Assets/` directory.
A document with animations names a companion `.bin`; keep it beside the document. A document without animations has no companion file. A missing asset, stale SHA-256, invalid
field or unsupported runtime feature reports the affected path. Failed Open leaves the active
scene available; repair the file or use the catalog to recover.

## Edit the document tree

Hierarchy follows document order and imported source nodes. Search retains ancestors of matches;
clearing it restores the tree. A source node can produce several material primitives. Its pose
and enabled controls affect all of them, so material names are not separate editable objects.
Sponza's converted asset, for example, exposes one Crytek Sponza source node with 25 primitives.

The Enabled checkbox on a group, object or light edits that subject's own state. Turning a group
off masks its descendants without erasing their choices. Disabled rows are muted and marked off;
frustum or occlusion rejection is a temporary view result, shown with its own reason. Disabled
objects keep their identities but contribute no image, shadow, outline or occluder coverage.

Generated children say “Generated by <lab> · not saved”. You can edit or toggle them for the
session. Their changes do not make the document dirty and are not exported. A document generator
node's own enabled flag is authored state; its generated children's edits are separate.

Select Environment to edit Exposure, Bloom and Shadows in Inspector. Reset restores that look
from the loaded or last successfully saved document. Sky and IBL describe the document's
required environment and are read-only. Reconstruction, scale, visibility, occlusion, submission,
lighting mode and diagnostic views stay in Window > Rendering and are not saved in the document.
Measurement disables scene edits while it holds the starting population.

## Save, Save As and Revert

1. Stop playback and finish or stop Measure. Save (`Cmd+S`), Save As… (`Cmd+Shift+S`) and Revert
   require Stopped with no active measurement.
2. Edit persistent subjects. The tree root and window title gain `*` when their canonical saved
   values differ from the loaded document. Restoring those values clears the marker. Save As and Open dialogs start in the active file's folder.
3. Save replaces the active document and its companion buffer, if it has one. Save As writes a new pair, adopts its
   path, and makes subsequent Save and Revert use that pair. Use a new path for experiments.
4. Revert reloads the active file. When dirty, the confirmation offers Discard or Cancel.

Open, a catalog switch, Revert, Quit and window close all confirm before discarding unsaved edits.
Cancel keeps the current document. Save must finish before the pending action proceeds; when
opening a file, it finishes before the chooser appears. Cancelling that chooser keeps the saved
state. Failed Save aborts the pending action, retains dirty state and displays its reason.

Save As rejects the active JSON or its actual companion buffer, including path aliases; use Save
to update the active pair. Read-only destinations fail without adopting a new path. The writer
rolls back ordinary reported write failures, but the two-file operation is not crash atomic.
A failed reread/hash after writing can leave changed disk bytes while the editor retains its old
baseline. Keep both files when backing up an experiment, and inspect the reported error before
reopening after a failed save.

Save canonicalizes a valid hand-edited file, even if it was clean when loaded. Canonical JSON uses
fixed key order and shortest round-trip floats; repeated save/load/save produces the same pair.
An edited orientation with no exact quaternion encoding in the supported search is saved as the
nearest quaternion, and the editor adopts that decoded value, so the document stays clean after
the save. Save refuses to overwrite a `.bin` the target document does not name.

## Cameras, playback and session overrides

Flying the editor camera does not alter the saved scene camera. View > Set Scene Camera from View
copies the current pose for the next Save. View > Reset Camera uses the adopted scene camera.
Play/Step animate a preview; Stop restores its captured state without adding dirty changes.
Animated imported poses are not saved as overrides. Existing unrelated edits remain dirty after Stop.

`--local-light-rig on|off` masks the document's top-level local-light group for the session; it is
a no-op without that group. Saving does not bake the CLI mask into authored flags. Lab population
arguments similarly override generator parameters for the run. Scene switches restore each
scene's own saved look. Workspace schema 4 continues to store docks, window bounds, visibility
and UI scale in build-local `imgui.ini`; it is independent of scene files.

## File contract and validation

Documents are glTF 2.0 with `KHR_lights_punctual`, standard cameras/animations and optional
`LMX_scene` schema 1. The [specification](../milestones/ux/ux3.md#the-lmx_scene-extension) lists
extension fields; [ADR 0028](../decisions/0028-scene-document-contract.md) remains Proposed.
Asset/HDRI URIs carry hashes; an asset hash covers the named file, while setup separately pins
its converted tree. Imported overrides use source-node index and a checked name. Runtime accepts
selected-camera LINEAR translation/rotation rails, referenced asset clips and generator motion.
Other document animation targets and transformed generator roots fail preflight. STEP scale keys are
validated, and an animated asset pose that cannot be decomposed holds the previous pose with one warning.

Run from the worktree root after setup:

```sh
xmake test -P . Tests/unit
python3 Tools/Scenes/validate_documents.py
```

The tests require canonical catalog bytes and emit writer fixtures under the test build's
`SceneDocuments/`. The script runs the pinned Khronos Validator over catalog and emitted files.
The macOS validator needs Rosetta; its launch error names that requirement. Passing syntax
validation alone does not establish that the runtime supports every valid glTF feature.

Capture manifest v3 and measurement schema 5 record `sceneDocument.path` and a SHA-256 over the
loaded JSON bytes followed by its animation buffer. The hash describes the loaded snapshot;
unsaved live changes are not part of it. PNG frame metadata stays unchanged. Image comparison
checks each reference document hash before rendering. The [validation record](../milestones/ux/ux3-validation.md)
retains failed exact-image gates, the provisional lab re-baseline and GUI verification limits.

## Session review

External changes to the open pair become file proposals after stable polling and a sidecar/hash
check. Pending file proposals block Save/Save As with “Review the pending proposal first”. Show
lists rows; Accept uses Revert and its Stopped/no-measurement and dirty Discard/Cancel guards.
Reject remembers the current hash; a later Save can overwrite the external file. Newer changes or
replacement stale old proposals. Matching sidecars provide attribution and relative evidence.
Bridge proposals accept only persistable Inspector fields and edit the saved scene camera without
moving the editor camera. Session scene.open shares replacement guards, preserves semantic
selection/current stopped view and refuses dirty, measuring or unstable-selection contexts.
See [Agent Session](agent-session.md) for sidecar syntax, subjects and operator approval.
